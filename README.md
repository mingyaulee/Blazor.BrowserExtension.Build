# Blazor.BrowserExtension.Build

[![NuGet](https://img.shields.io/nuget/v/Blazor.BrowserExtension.Build?style=for-the-badge&color=blue)](https://www.nuget.org/packages/Blazor.BrowserExtension.Build/)
[![Build](https://img.shields.io/github/actions/workflow/status/mingyaulee/Blazor.BrowserExtension.Build/Blazor.BrowserExtension-Build.yml?branch=main&style=for-the-badge&color=blue)](https://github.com/mingyaulee/Blazor.BrowserExtension.Build/actions/workflows/Blazor.BrowserExtension-Build.yml)

This repository contains the build tasks and Roslyn source generator used to build Blazor WebAssembly browser extensions. The `Blazor.BrowserExtension.Build` NuGet package includes the analyzer.

For usage guidance, see the [Blazor.BrowserExtension documentation](https://mingyaulee.github.io/Blazor.BrowserExtension).
